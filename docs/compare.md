# Compared with other tools

Pick a tool for your Yandex Disk by the job you want done: search inside your documents, back up whole folders, or
let an agent work with files. The comparison of `ydisk` with rclone, Yandex's own apps and the Yandex Disk MCP servers
lives on wirecat.dev, because it changes when the other tools change, not when `ydisk` is released.

**On this page:**

1. [What the comparison covers](#what-the-comparison-covers)
2. [Read the comparison](#read-the-comparison)

## What the comparison covers

It compares `ydisk` with the Yandex Disk MCP server that Yandex runs, rclone, Yandex Disk for Linux and the
yandex-disk-mcp server. For each job it shows which tool does it: finding a document by its words or its meaning,
reading a file, working with files on the Disk, keeping an agent read-only, and signing in. Every mark has its source
and the date it was checked. It also says where another tool fits better, such as backing up whole folders.
