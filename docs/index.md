# ydisk

`ydisk` is a WireCat command-line tool for Yandex Disk, for the terminal, for scripts and for AI agents. It copies
the text of the folders you choose into WireCat's local store for search, and works with the files live: list,
download, upload, copy, move, delete to the trash, restore and public links.

It has the commands every WireCat CLI shares: `doctor`, `commands`, `config`, `skill`, `mcp`, `runs` and `upgrade`;
the shared documents commands: `folders`, `sync`, `status`, `documents`, `search`, `catalog`, tags, notes and
memories; and its own `session`, `files` and `api`.
Start with [installation](installation.md), then [usage](usage.md).
